# Other built-in features

- Auto-generated TOC from headings
- Collect and list tags per post and globally
- Paginate long lists
- Feeds at `/atom.xml`
- Generate auto `/sitemap.xml`, `/robots.txt`
- Generate img_url from config/front-matter for meta tags for social sharing
- Calculate words count, read times of content
- Support Katex for math
- Display mermaid diagram
